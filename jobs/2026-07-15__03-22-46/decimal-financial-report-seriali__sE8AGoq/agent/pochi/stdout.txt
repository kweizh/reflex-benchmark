## Key Implementation Details

### Custom Serializers (`@rx.serializer`)
Registered before state/UI definitions so they apply to all `decimal.Decimal` and `datetime.datetime` values across state vars, computed vars, and display:
- **`serialize_decimal`** → `$1,000.00` (positive) / `-$234.56` (negative), with thousands comma-grouping and exactly 2 decimal places
- **`serialize_datetime`** → `YYYY-MM-DD HH:MM` (24-hour)

### State (`class State(rx.State)`)
- `entries: list[LedgerEntry]` — seeded with the 4 required entries (Opening balance, Grocery store, Salary, Electric bill) as `@dataclass` objects holding raw `Decimal` + `datetime` values
- **Computed vars** (all return `decimal.Decimal`, serialized automatically):
  - `running_balances` → cumulative sum list aligned with `entries`
  - `total_credits`, `total_debits`, `net_balance`
- **Event handlers**: `set_new_description`, `set_new_amount`, `add_entry` (parses amount as `Decimal`, stamps with `datetime.now()`)

### UI
- **Ledger table**: `rx.foreach(rx.Var.range(State.entries.length()), ledger_row)` — iterates by index to simultaneously access `State.entries[i]` and `State.running_balances[i]`; columns: Description | Amount (color-coded) | Timestamp | Balance
- **Totals row**: three `rx.card` widgets showing Total Credits (green), Total Debits (crimson), Net Balance
- **Add-entry form**: Description input + Amount input + "Add Entry" button, with inline error callout for invalid input
