## What was built

### `note_app/note_app.py`
- **`Draft` model** — a plain `sqlmodel.SQLModel` table (`table=True`) with `id` (PK) and `content` columns, persisted in `reflex.db` (SQLite).
- **`State(rx.State)`** — the app state with:
  - `content: str` — public var bound to the text area value.
  - `_is_dirty: bool` — backend-only flag, `True` when edits are unsaved.
  - `_is_saving: bool` — backend-only flag, `True` while the background task is running; guards against redundant concurrent saves.
  - `_saved_at_label: str` — backend-only string holding the last "Saved at HH:MM:SS" message.
  - `status_label` — `@rx.var` computed var returning `"Unsaved"` / `"Saving..."` / `"Saved at HH:MM:SS"`.
  - `on_load()` — page on-load handler that restores the draft from SQLite.
  - `handle_change(value)` — sets content, marks dirty, returns `State.autosave_task`.
  - `autosave_task()` — `@rx.event(background=True)` async handler that sleeps 1 s outside the state lock (quiet period), then writes to SQLite via `rx.session()`, then updates state flags.
- **`index()` page** — an `rx.container` with a heading, a colour-coded `rx.badge` showing the status label, and an `rx.debounce_input` (800 ms timeout) wrapping an `rx.text_area`.
- Page registered with `on_load=State.on_load`.
