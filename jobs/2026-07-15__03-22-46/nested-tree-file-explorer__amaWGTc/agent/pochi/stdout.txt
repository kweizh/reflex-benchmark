## Architecture

### Data Model (`TreeNode` dataclass)
A self-referential dataclass with `name`, `is_dir`, `node_id`, and `children: list[TreeNode]`. The complete required tree is defined as a module-level constant `TREE`.

### State Flattening Strategy
Instead of recursive components (which are problematic in Reflex), the tree is **flattened on every state change** into a `list[FlatRow]` computed var. Each `FlatRow` stores `node_id`, `name`, `is_dir`, `depth`, and `path` (the breadcrumb string). Only visible nodes (those whose ancestor folders are all expanded) appear in the list — the `_build_flat()` helper recursively walks the tree and only descends into nodes that are in the `expanded` set.

### State (`State(rx.State)`)
- `expanded: list[str]` — initially `["root"]`, updated by `toggle_folder(node_id)`
- `selected_id: str` and `selected_path: str` — updated by `select_file(node_id, path)`
- `flat_rows` — `@rx.var` computed var returning the visible `list[FlatRow]`
- `file_count` — `@rx.var` returning `5` (statically counted from the tree)

### Rendering
- `rx.foreach(State.flat_rows, render_row)` iterates over the reactive flat list
- `render_row()` uses `rx.cond` to show either a folder (📁, clickable to toggle) or file (📄, clickable to select) row
- Indentation uses `(row.depth * 20).to_string() + "px"` — a reactive Var expression so it works correctly inside `rx.foreach`
- Breadcrumb uses `rx.cond(State.selected_path == "", rx.text("No file selected"), rx.text(State.selected_path))`
- File count rendered as `rx.text("Total files: ", State.file_count)`
