## State Design

**Synchronized vars** (sent to the browser):
- `content: str` — the current committed text, shown in `#content-display`
- `input_value: str` — the live value of the text input field

**Backend-only vars** (underscore-prefixed, never serialized to the client):
- `_undo_stack: list[str]` — snapshots available for undo
- `_redo_stack: list[str]` — snapshots available for redo

**Computed vars** (`@rx.var`):
- `can_undo` → `bool` — true when `_undo_stack` is non-empty
- `can_redo` → `bool` — true when `_redo_stack` is non-empty
- `history_label` → `str` — exactly `"Undo depth: <u> | Redo depth: <r>"`

## Event Handler Logic

| Handler | Behaviour |
|---|---|
| `commit()` | Pushes `content` → undo stack (capped at 50); sets `content = input_value`; clears redo stack |
| `undo()` | Pushes `content` → redo stack; pops undo stack → `content`; syncs `input_value` |
| `redo()` | Pushes `content` → undo stack (capped at 50); pops redo stack → `content`; syncs `input_value` |
