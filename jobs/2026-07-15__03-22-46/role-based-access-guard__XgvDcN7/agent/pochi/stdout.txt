## Architecture

### Password Security
- Passwords are **never stored in plaintext** — each is salted with `secrets.token_hex(32)` and hashed using PBKDF2-HMAC-SHA256 (260,000 iterations) at module load time
- The in-memory `_USERS` dict lives **only on the backend server process**; nothing is sent to the browser
- Comparison uses `secrets.compare_digest` to prevent timing attacks

### State (`State(rx.State)`)
- **Backend-only fields** (prefixed `_`, never serialised to client): `_username`, `_role`, `_login_error`
- **Computed vars** (derived from backend fields, safe to expose): `is_authenticated`, `is_admin`, `current_username`, `current_role`, `login_error`
- **Event handlers**: `login()`, `logout()`, `require_auth()`, `require_admin()`, `redirect_to_login()`

### Pages & Routes

| Route | Access | Guard |
|---|---|---|
| `/` | public | `on_load` → always redirects to `/login` |
| `/login` | public | none |
| `/dashboard` | authenticated | `on_load=State.require_auth` → `/login` if not authenticated |
| `/admin` | admin role only | `on_load=State.require_admin` → `/login` or `/forbidden` |
| `/forbidden` | public | none |

### Page content
- `/login`: username + password form; shows `Invalid credentials` on bad login
- `/dashboard`: displays `Dashboard` heading, logged-in username, and role; Logout button
- `/admin`: displays `Admin Panel` heading; Logout button
- `/forbidden`: displays `Access Denied` heading
